# Обработка банковских платежей

Браузерное приложение для разбора выписок из банка: загрузка, сопоставление поступлений с ожидаемыми платежами (график платежей покупателей / счета), категоризация расходов, экспорт результата.

**Без сервера и без установки.** Откройте `index.html` в браузере (двойной клик). Данные хранятся только в `localStorage` этого браузера и никуда не отправляются. Чтобы перенести данные или сделать резервную копию: меню «Данные» → «Скачать резервную копию» (JSON).

## Как работать

1. **Выписки** — перетащите файл выписки (CSV / TXT / XLSX / XLS) или вставьте таблицу из Excel/интернет-банка.
   - Строка заголовка и колонки определяются автоматически (подсказки на английском, русском и тайском: Date/Дата/วันที่, Withdrawal/Расход/ถอน, Deposit/Приход/ฝาก, …). Если что-то не так, поправьте в выпадающих списках над колонками.
   - Поддерживаются: одна колонка суммы со знаком **или** отдельные колонки «приход/расход»; форматы `1,234.56`, `1 234,56`, `(500)`, `500-`, `500 DR`; даты `ДД/ММ/ГГГГ`, `ГГГГ-ММ-ДД`, `15-Jan-2026`, `15 ม.ค. 2569`; **буддийский год** (2569 → 2026) переводится автоматически; кодировки UTF-8, Windows-1251, Windows-874.
   - Повторная загрузка той же выписки не создаёт дублей (операция определяется по счёту, дате, сумме, назначению и остатку).
2. **Ожидаемые поступления** — загрузите CSV с колонками *код* (юнит / договор / счёт, напр. `B-1204`), *сумма* и по желанию *плательщик, проект, срок, описание*. Можно добавлять вручную.
3. **Платежи** — основной экран:
   - **Автосопоставление** — каждому поступлению подбирается ожидаемый платёж. Оценка 0–100:
     код в назначении платежа (+55, `B-1204` находит и `B1204`, `b 1204`), совпадение суммы с остатком (+30), имя плательщика (до +20), дата близко к сроку (+10).
     ≥ 80 и явный лидер → «Сопоставлена» автоматически; 35–79 → «Проверить» (предложение нужно подтвердить); иначе остаётся «Новая».
   - Клик по строке открывает карточку: кандидаты с причинами, ручной поиск, категория, комментарий.
     Горячие клавиши: `↑/↓` — соседняя операция, `Enter` — подтвердить предложение, `I` — игнорировать, `/` — поиск, `Esc` — закрыть.
   - Массовые действия по выделенным строкам: категория, подтверждение, игнор, сброс.
   - **Экспорт CSV** (по текущему фильтру) — открывается в Excel (UTF-8 с BOM).
4. **Правила** — «если текст содержит … → категория / игнорировать», можно использовать регулярные выражения `/fee|комиссия/`. Ручные правки правилами не перезаписываются. Из карточки операции можно создать правило в один клик.

На вкладке «Ожидаемые поступления» видно, что оплачено, частично оплачено, просрочено, и какие платежи из выписки закрыли каждую позицию.

## Демо

Меню «Данные» → «Загрузить демо-данные» — вымышленная выписка и график платежей из `samples/`. Эти же файлы можно загрузить вручную, чтобы попробовать импорт.
`samples/demo-data.js` сгенерирован из CSV-файлов (нужен, чтобы демо работало при открытии через `file://`).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка и стили |
| `core.js` | логика без зависимостей: разбор CSV, распознавание колонок, даты/суммы, правила, сопоставление |
| `app.js` | интерфейс |
| `tests/core.test.js` | тесты логики: `node --test tests/core.test.js` |

## Ограничения

- Чтение XLSX/XLS подгружает библиотеку SheetJS с `cdn.sheetjs.com` при первом открытии Excel-файла (сам файл в интернет не отправляется). Без интернета сохраните выписку как CSV.
- Форматы MT940 / CAMT.053 и PDF-выписки пока не поддерживаются.
- Данные живут в одном браузере; совместной работы нескольких человек нет. Для этого понадобится сервер и подключение к SID OS.
